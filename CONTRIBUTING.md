# Guias de Contribuição
Obrigado por se interessar em contribuir pros meus 10 centavos.
Esse documento vai te explicar o que seguir e como contribuir para o projeto

## Como posso ajudar?

Você pode ajudar com:
 * Resolver erros gramaticais nos documentos
 * Adicionar mais assuntos no projeto
 * Auxiliar as pessoas nas issues

## Como começar?

A forma de contribuição do projeto é via Fork.
 * Comece fazendo um fork do projeto
 * Clone o repositório: `git clone https://github.com/seu-user/meus10centavos`
 * Crie uma nova branch com o tema que há de ser abordado: `git checkout -b new-note/titulo-da-nota`
 * Faça o que tiver de ser feito
 * Abra um PR
## Convenções

* Sempre escreva formalmente os conteúdos e não cite questões que não estejam intimamente ligadas com o tópico abordado. Caso não estejam ligadas ao tópico abordado, que seja então como uma forma de exemplificar melhor a ideia.
* Não escreva palavrões, e evite exprimir a usa opinião própria sobre um assunto
* Todos os conteúdos são colocados em /content e seguem o formato `ANO-MES-DIA-titulo.md`

## Reportando Problemas

Use as issues do github para:
* Citar documentos que não seguem as convenções do projeto
* Alertar sobre conteúdo desatualizado 
* Alertar sobre conteúdo mal escrito 
* Proponha junto disso uma solução do problema listado

## Código de Conduta

Seja respeitoso, inclusivo e construtivo para com os outros.
